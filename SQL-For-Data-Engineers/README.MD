## 📌 Repository Overview

> **"Systems thinking applied to relational data. Moving past basic querying into production-oriented SQL transformation, optimization, and analytical modeling."**

SQL is the foundational layer of my transition into Data Engineering. This repository tracks my progression from structural table setups to advanced transformational scripts, documenting complex logic patterns used to clean, parse, and prep raw data for modern cloud platforms.

---

## 🏗️ Core Focus Areas & Patterns

```text
DDL / DML Baseline ──► Window Engineering ──► Relational Modeling ──► Production Logic
(Star Schema Setup)    (Rank/Lag/Lead)        (CTEs & Joins)          (Deduplication)
```

### 🟢 Active Core Implementations
* **Advanced Window Functions:** Implementing `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, and transactional positioning using `LAG()` / `LEAD()`.
* **Complex Transformations:** Writing structured `CASE` operations, explicit `NULL` validation patterns, and conditional data parsing.
* **Modern Query Structures:** Utilizing heavily optimized **Common Table Expressions (CTEs)** and subqueries over deep, nested datasets to avoid procedural overhead.
* **Data Warehousing Patterns:** Crafting standard analytical dimensional logic including:
  * Star Schema structural execution (`fact_sales` ↔ dimensions)
  * Deduplication pipelines and **Latest Record** identification logic
  * Rolling computations and multi-conditional filtering blocks (`WHERE` vs `HAVING`)
